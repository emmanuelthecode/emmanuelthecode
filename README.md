## 🚀 Selected Work

### AI Predictive Maintenance Dashboard

Built an end-to-end machine learning system using the AI4I 2020 dataset.

- Compared Logistic Regression, Decision Tree, Random Forest and Gradient Boosting
- Selected Decision Tree based on **75.4% failure-class recall**
- Achieved **70.8% F1 score**
- Built an interactive Streamlit prediction dashboard

➡️ [View the project](https://github.com/emmanuelthecode/Predictive-Maintenance-AI)

### Green AI for Software Engineering

A systematic survey of energy-efficient techniques for AI coding tools, plus a
NumPy benchmark that measures them on a real code-classification task.

- float32 + early stopping cut training energy by **92%** for a 0.3-point accuracy cost
- LoRA adapted the model to a new task training **2.3% of the parameters** with 63% less energy
- Showed why unstructured pruning cuts FLOPs but not energy, and structured pruning cuts both

➡️ [View the project](https://github.com/emmanuelthecode/green-ai-for-software-engineering)

### Airline Crew Scheduling with Metaheuristics

Simulated annealing and two genetic algorithms (penalty-based vs. stochastic
ranking) for the Set Partitioning Problem on real OR-Library airline instances.
All three reach the known optima; SA was by far the most consistent.

➡️ [View the project](https://github.com/emmanuelthecode/aircrew-scheduling-metaheuristics)
